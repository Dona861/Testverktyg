# Exam Project

## Beskrivning

Detta projekt innehåller backend- och frontendtester för webbsidan Läslistan.

Projektet använder:

- Python + Pytest för backendtester
- Playwright + Cucumber för frontendtester
- GitHub Actions för CI

---

## Installation

### Klona projektet

```bash
git clone <din-github-länk>
cd exam-project
```
